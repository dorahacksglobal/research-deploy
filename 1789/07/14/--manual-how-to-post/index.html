第一步：上传文章中的图片及其他必需的文件

  • 参见〈如何上传图片或其他文件〉。
  • 完成后记录各文件的 URL。

第二步：准备好 Markdown 格式的文章内容

  1. 建议在本地准备好 Markdown 格式的文本，校对内容，并保证基本的语法及格式正确；另见 “Dora-flavoured Markdown”。
  2. 用第一步中获取到的 URL，填充 Markdown 文章中需要外链的图片或其他文件地址。
  3. 下载文章模板（若浏览器没有直接下载，按 [ctrl + s] 或 [command + s] 保存页面即可），打开并修改头部的元数据：
    • 元数据采用 YAML 语法——不用太在意语法，按照注释信息（也就是写在 # 之后的文字）修改到合适的状态即可；
    • 元数据中的值（也就是写在 : 之后的内容）是大小写敏感的；
    • 建议用纯文本编辑器打开该文件，如果出现乱码，请将编辑器的默认编码改为 UTF-8；
    • 文章主标题只需填写在元数据中，正文内请勿重复。

4. 点击页面下方 Commit new file 按钮（上方输入框可选填，选项保持默认的「Commit directly …」，与「上传文件」的操作基本相同）。

5. 文章发布可能需几十秒到几分钟，成功后访问网站 doraresear.ch 即可浏览。

方法二：自定义 permalink 模式

元数据中的 permalink 参数，可供自定义文章地址（参见附录一）。借助这个特性，你可以先在本地编辑好 Markdown 文件，然后直接上传到 GitHub（无需在 GitHub 上创建文件、设定文件名）。只需注意三个约定：

  1. Markdown 文件命名为 yyyymmdd-my-post-name.md（类似图片命名）；
  2. Permalink 设定成 yyyy/mm/dd/my-post-name/（与默认格式一致，注意结尾处的 / 不可遗漏）；
  3. 上传到 source/_posts/custom-permalink 文件夹。

自定义 permalink 可让文章地址（URL）跟日期和文件名解耦。因此，我们依赖上述三个约定来保证文章地址格式统一，并保证 Markdown 源文件便于检索且不易重名。

注意

  • 我们推荐用「日期文件夹」组织 Markdown 源文件，便于管理和检索。
  • 发布文章的命名规范，与「上传文件」很相似。在 GitHub 上输入的文件名 yyyymmdd/my-post-name.md 包含两个部分：
    • yyyymmdd 是八位数日期，输入斜杠 / 后，它会自动转变成文件夹；
    • my-post-name.md 是 Markdown 文件名，注意不要忘记 .md 后缀；
    • my-post-name 非常重要，它将默认构成文章的 permalink，请根据文章标题或主旨起一个简洁的名称，尽量只用拉丁字母和数字，字母全小写；
    • 例如：文章发布于 2021 年 10 月 17 日，主题为「Decentralize The Hacker Movement」，则文件名为 20211017/decentralize-the-hacker-movement.md，发布成功后，文章地址自动生成为：https://doraresear.ch/2021/10/17/decentralize-the-hacker-movement/。
  • 如果某一天有多篇文章，将它们存在同一日期的文件夹内即可。
  • 如需删除文件或文件夹，通过 GitHub 界面找到对应文件或文件夹，通过右上方的删除按钮即可操作。
  • 在 GitHub 上还可以随时修改文章内容——包括它的文件名，以及它所在的文件夹——试试将光标放到文件名的开头，并按退格键。

故障排除

  • GitHub 界面的文件列表顶栏，有一图标，指示此前上传操作的各种状态——这与「上传文件」的界面几乎相同——借此可快速了解此前操作的结果。
  • 其他故障，联系开发者解决。

附录一：关于 permalink

Permalink（固定链接/永久地址）是网页持久不变的地址，应该简洁可读。Dora Research 希望文章地址跟日期和文件名高度耦合，形如 doraresear.ch/yyyy/mm/dd/file-name/。

而通过元数据的 permalink 参数可以任意设定文章地址，例如：

  • Markdown 文件名是 my-post-name.md，日期是 date: 2011-10-17，默认地址本应是 doraresear.ch/2011/10/17/my-post-name/；
  • 通过设定 permalink: "custom-permalink/"，文章地址将被改写成 doraresear.ch/custom-permalink/；

可见，permalink 参数无视日期和文件名，直接设定文章地址。所以应当遵循一定的命名规则，以免产生混乱。

附录二：文章模板

文章模板的全文如下，可直接复制使用：

---
title: "Article title"  # 保留头尾的引号，技术上比较安全
date: yyyy-mm-dd  # 显示在网页上的文章发布日期，可按需设定，例如：1789-07-14
#permalink: "yyyy/mm/dd/article-title/"  # 慎用；如需使用，删除本行最开头的 `#`
author: "Author Name"  # 保留头尾的引号，技术上比较安全
lang: en  # 如果是中文文章，改成：zh（注意是全小写）
mathjax: true  # 如果不需要数学公式支持，删去这行
categories:  # 删去不想要的分类（删去整行）
- [BioTech]
- [Frontier DAO]
- [DoraHacks Newsletter]
- [Privacy & Simulations]
- [Quantum Computing]
- [English]
- [中文]
excerpt: "Leave a short message to summarize this article."  # 选填（保留头尾的引号，不填可直接删去这行），对 SEO 和社交网站分享有用
---
