如何上传图片或其他文件

14 Jul 1789

Zhengyu Qian

如果你会用 Git，可将 dorahacksglobal/images clone 到本地，把图片文件 commit 到 image/ 目录，并 push 到 master 分支上，等待布署完成即可。布署后的图片地址形如：https://dorahacksglobal.github.io/images/image/mypic-filename.ext。

预设的 image/、audio/、video/ 和 misc/ 四个目录，可供文件分类存放。使用时注意我们的文件命名约定。

如何上传图片

1. 进入 dorahacksglobal/images 仓库，点击 image 文件夹：

2. 点击 Add file → Upload files：

3. 选择并上传本地的图片文件（注意文件命名），点击页面下方 Commit changes 按钮（上方输入框可选填，选项保持默认的「Commit directly …」）：

4. 图片上传可能需几十秒到几分钟，完成后可通过如下网址访问：https://dorahacksglobal.github.io/images/image/mypic-filename.ext

  • https://dorahacksglobal.github.io/images/ 是固定网址；
  • image/ 是图片文件夹名；
  • mypic-filename.ext 是图片文件名，含后缀。

5. 记录各文件的 URL，供文章使用。另见〈如何发布文章〉。

如何上传其他文件

上传其他文件的方法，与上传图片几乎完全相同。我们预设了四种分类：

  • 图片，上传至 image 文件夹；
  • 音频，上传至 audio 文件夹；
  • 视频，上传至 video 文件夹；
  • 其他格式的文件（如 PDF、DOC、CSV……），均上传至 misc 文件夹。

注意

  • 上传文件前，在本地将文件名修改成合适的状态。
    • 为文件起一个简洁但语义明确的名称，尽量只用拉丁字母和数字；
    • 文件命名格式建议为 yyyymmdd-my-file-title.ext，字母全小写；
    • 例如：文章发布于 2021 年 10 月 17 日，图片名为「Hackathon DAO」，图片格式为 PNG，则文件名为 20211017-hackathon-dao.png，上传成功后图片地址即为：https://dorahacksglobal.github.io/images/image/20211017-hackathon-dao.png。
  • 同一文件夹内，请避免上传文件名完全相同的文件。
  • 如需「替换」文件，请直接将新文件重命名后上传。
    • 例如旧文件 yyyymmdd-my-file.ext，新文件 yyyymmdd-my-file-v2.ext；
    • 删除旧文件并上传同名新文件，可能会因为缓存机制而难以刷新。
  • 如需删除文件（通常不必），可通过 GitHub 界面找到具体的文件并打开，右上方即有删除按钮——点击后依提示操作即可。

故障排除

  • GitHub 界面的文件列表顶栏，有一图标，指示此前上传操作的各种状态（可能须刷新网页）：
    • 绿勾：上传成功；
    • 红叉：上传失败；
    • 橙点/无图标：正在处理中……
    • 点击图标，可浏览更多详情。
  • 其他故障，联系开发者解决。
